Evelyn and the TimeBand: The Golden Spike (draft for review, not yet recorded)
Open golden-spike.html in Chrome or Edge. Keep the img folder next to it. Works offline.
No narrator recording yet: "Read to me" uses the device's built-in voice for now.
PAUSE: the big round button at the top (green play / orange pause) pauses and plays. It picks up again from the same word. The space bar does the same on a keyboard.
Tap any word to hear it from there. Grown-up menu = gear button (endings found, auto-read option, voice).
If an Android tablet will not show pictures from this folder, use golden-spike-single.html instead.
